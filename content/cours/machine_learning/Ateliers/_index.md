## Évaluation
Ces ateliers comptent pour **20%** de votre session.
| atelier | % |
|---|---|
| Partie 1 - Apprentissage (venv) | **5%** |
| Partie 2 - Analyse d'image (venv) | **5%** |
| Partie 3 - Llm agentique (docker) | **10%** |
| **Total** | **20%** |

- Vous aurez besoin de VScode, docker et venv python pour ces ateliers. 
- Cet atelier est à faire en python, plus particulièrement avec les [jupyter notebook](../../../base%20de%20connaissances/python/notebook/). 

[<i class="fa-brands fa-github"></i> Repos Github](https://github.com/T-Piquet/420-5G4-ML) pour les remises des 3 ateliers.

> Le travail se fait seul.

> [!warning] Attention
> Faites votre **pull request** une fois la dernière partie (llm agentique) terminée.
